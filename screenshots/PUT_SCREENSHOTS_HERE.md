# Screenshots go here

Once you've deployed the app (or run it locally) with your real Groq API key, take
at least 3 screenshots and drop them into this folder, e.g.:

- `01-summary.png` — the Summary tab with generated output
- `02-flashcards.png` — a flipped flashcard
- `03-quiz.png` — the quiz with answers checked (showing correct/incorrect highlighting)

Then reference them in the main README.md like:

```markdown
![Summary feature](screenshots/01-summary.png)
![Flashcards feature](screenshots/02-flashcards.png)
![Quiz feature](screenshots/03-quiz.png)
```

Delete this file once your real screenshots are in place.
